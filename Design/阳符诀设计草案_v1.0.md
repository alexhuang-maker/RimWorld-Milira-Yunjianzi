# 阳符诀设计草案 v1.0

## 总纲

> 古有五经论道，观天地广阔、五行变换，皆可采其意而书于符中。符可护身益生，亦可蕴火、雷、风、兵之术；一纸虽轻，落笔即成法。

阳符诀分为“随身符箓”和“战斗术符”两项独立技能。随身符箓负责生活或战斗强化，战斗术符负责主动施法。二者都从画符台制作出的实体符箓出发，但不会占用普通服装层，以免破坏云间道袍和米莉拉身体图层。

## 一、画符台与随身符位

- 新增画符台，用于制作阳符诀专属符箓。
- 制成的符箓可以存放、携带、替换和交易；装入云间子的专属符位后才会生效。
- 专属符位不视为普通衣物，不与道袍、护甲、头饰或种族图层冲突。
- 境界提升会增加可同时生效的符位数量，具体数量在平衡阶段核定。
- 换符应当是主动操作，不进行高频自动扫描。

## 二、随身符箓

随身符箓装入后持续生效，其中既有生活型符箓，也有强化自身的战斗型符箓。右键技能入口用于选择当前要装配或切换的符箓。

生活型效果例如：

- 劳作、制作、研究或修炼效率；
- 休息效率、进食效率或需求衰减；
- 心境、恢复、环境耐受或移动便利。

战斗强化型效果例如：

- 命中、闪避、移动、近战或远程防护；
- 剑罡恢复、灵力流通或受击稳定；
- 对御剑诀、仙阵诀、神机诀的有限联动。

## 三、战斗术符施放方式

- 战斗术符使用一个统一的技能入口：右键在已掌握术式间切换，左键释放当前术式。
- 当前设定的三种术式各自拥有独立技能图标。
- 三种术式各自沿境界直线进阶，不互相分叉，也不把其中一种的强化作为另一种的前置。
- 每条路线分别定义灵力消耗、冷却、作用范围与境界强化。

## 四、三条术符路线

### 火龙卷

召唤可移动的烈焰旋风，沿途灼烧并扰乱敌阵。基础伤害不追求瞬间爆发，主要表现为持续推进、路径伤害和区域驱赶。

直线进阶方向：持续时间 → 移动与追踪 → 覆盖范围 → 燃烧强度与视觉规模。

### 天雷神风

先以神风牵引范围内敌人，将其汇聚到施术中心，再降下雷霆轰击。它承担聚怪和控制职责，雷击提供收束伤害。

直线进阶方向：牵引范围 → 聚拢强度 → 雷击轮数 → 控制时长与更稳定的敌我识别。

### 撒豆成兵

将符豆化为短暂存在的符兵。符兵不参与劳作、救援或长期战斗，只会寻找敌人、冲向目标，并在接触目标或寿命结束时自毁爆炸。

直线进阶方向：召唤数量 → 寻敌与移动 → 爆炸半径 → 高境界的连锁或分裂表现。

## 五、待下一轮确定

- 画符台材料、工作量、研究前置和符箓消耗品；
- 三种术符及“展开/切换阳符”的四套技能图标。
