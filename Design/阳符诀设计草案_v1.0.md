# 阳符诀设计草案 v1.0

## 总纲

> 古有五经论道，观天地广阔、五行变换，皆可采其意而书于符中。符可护身益生，亦可蕴火、雷、风、兵之术；一纸虽轻，落笔即成法。

阳符诀分为“随身符箓”和“战斗术符”两项独立技能。随身符箓负责生活或战斗强化，战斗术符负责主动施法。二者都从画符台制作出的实体符箓出发，但不会占用普通服装层，以免破坏云间道袍和米莉拉身体图层。

## 一、画符台与随身符位

- 新增画符台，用于制作阳符诀专属符箓。
- 制成的符箓可以存放、携带、替换和交易；装入云间子的专属符位后才会生效。
- 专属符位不视为普通衣物，不与道袍、护甲、头饰或种族图层冲突。
- 境界提升会增加可同时生效的符位数量，具体数量在平衡阶段核定。
- 换符应当是主动操作，不进行高频自动扫描。

## 二、随身符箓

随身符箓装入后持续生效，其中既有生活型符箓，也有强化自身的战斗型符箓。右键技能入口用于选择当前要装配或切换的符箓。

生活型效果例如：

- 劳作、制作、研究或修炼效率；
- 休息效率、进食效率或需求衰减；
- 心境、恢复、环境耐受或移动便利。

战斗强化型效果例如：

- 命中、闪避、移动、近战或远程防护；
- 剑罡恢复、灵力流通或受击稳定；
- 对御剑诀、仙阵诀、神机诀的有限联动。

### 符位数量

| 境界 | 同时生效符位 |
|---|---:|
| 练气 | 0 |
| 筑基 | 1 |
| 紫府 | 2 |
| 金丹 | 3 |
| 化神 | 4 |

符位只限制同时生效数量，不限制已经学会、制作或储存的符咒。更换符咒是一次明确的玩家操作，不进行逐 tick 扫描。

### 筑基级随身符

- **啄玉符**：提高制作成品的品质判定；第一版目标为品质结果提高两阶，但不突破游戏允许的最高品质。
- **神截符**：将天地神妙秘藏截于自身，大幅提高研究速度。
- **神行符**：大幅提高移动速度。
- **寄情符**：寄情山水草木，按周边环境美观度获得心情与社交魅力；环境越华丽，增益越高。
- **百草符**：大幅提高医疗与手术能力，并把灾难性医疗失败降为普通失败；它不保证所有治疗必然成功。
- **心剑符**：洞彻人心，提高谈判能力和贸易价格优势。

### 紫府级随身符

- **北斗符**：北斗星辉融入法器，增加攻击速度，并缩短诛邪附魔、落雷等武器特效的内部冷却。
- **归海符**：真元如海、万脉归流，大幅提高灵力自然恢复与打坐回灵速度，但不额外增加灵力上限。
- **神炼符**：大幅提高制作类工作的速度，不与啄玉符的品质提升混为同一效果。
- **惠剑斩念符**：斩断外来邪念，免疫心灵低语、灵能低鸣与类似负面精神扰动；普通生活事件造成的心情变化仍然有效。

### 金丹级随身符

- **不昧真灵符**：凝聚万世记忆、抵达不昧心境。装备期间心境保持圆满，并提高阳符与其他主动法门的施放速度。该设定取意于《了不起的修仙模拟器》的“不昧真灵”。
- **劫心符**：以本源心血淬炼肉身，全面提高意识、移动、操作、血液循环与战斗表现；启用时附带持续的“本源亏损”，形成明确代价。
- **六阳真形符**：射击与格斗按20级结算，大幅强化战斗能力；艺术按0级结算，并因纯阳浮躁承受显著心境惩罚。

### 化神级随身符

- **天道符**：既度天劫，洞彻天道。所有未被背景故事禁止的技能按20级结算；不会解除“无法从事”的工作类型。
- **换日符**：偷天而后换日。生理年龄停止增长，时间年龄与游戏时间仍正常推进，也不会逆转已经存在的衰老疾病。

## 三、战斗术符施放方式

- 战斗术符使用一个统一的技能入口：右键在已掌握术式间切换，左键释放当前术式。
- 当前设定的三种术式各自拥有独立技能图标。
- 三种术式各自沿境界直线进阶，不互相分叉，也不把其中一种的强化作为另一种的前置。
- 每条路线分别定义灵力消耗、冷却、作用范围与境界强化。

## 四、三条术符路线

### 火龙卷

召唤可移动的烈焰旋风，沿途灼烧并扰乱敌阵。基础伤害不追求瞬间爆发，主要表现为持续推进、路径伤害和区域驱赶。

直线进阶方向：持续时间 → 移动与追踪 → 覆盖范围 → 燃烧强度与视觉规模。

### 天雷神风

先以神风牵引范围内敌人，将其汇聚到施术中心，再降下雷霆轰击。它承担聚怪和控制职责，雷击提供收束伤害。

直线进阶方向：牵引范围 → 聚拢强度 → 雷击轮数 → 控制时长与更稳定的敌我识别。

### 撒豆成兵

将符豆化为短暂存在的符兵。符兵不参与劳作、救援或长期战斗，只会寻找敌人、冲向目标，并在接触目标或寿命结束时自毁爆炸。

直线进阶方向：召唤数量 → 寻敌与移动 → 爆炸半径 → 高境界的连锁或分裂表现。

## 五、待下一轮确定

## 六、已实装：画符生产链

- `云间画符台` 为 2×3、可旋转和卸载的工作台，位于“文化”建筑分类，不要求任何特定文化或理念。
- 修行面板中的阳符诀已经拆为可学习节点；只有玩家阵营中至少一位云间子掌握对应节点时，该符咒的账单才会出现在画符台。
- 十五种随身符均有独立物品 Def 与同画风、不同中心符印的小图标。
- 造价按材料实际市场价值控制在以下量级（织物价格会令最终数值有少量浮动）：

| 境界 | 目标价值 | 材料结构 |
|---|---:|---|
| 筑基 | 约500 | 40织物、20翡翠、8日棱晶、15日光燃料 |
| 紫府 | 约1500 | 60织物、40翡翠、20日棱晶、40日光燃料、20日盘钢 |
| 金丹 | 约3000 | 80织物、70翡翠、40日棱晶、70日光燃料、50日盘钢 |
| 化神 | 约5000 | 100织物、100翡翠、70日棱晶、100日光燃料、95日盘钢 |

当前阶段完成的是“学习—解锁配方—制作物品”闭环；符位装备界面与十五种佩符效果继续按本文前述规则实现。
