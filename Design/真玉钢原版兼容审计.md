# 真玉钢原版材质兼容审计

## 兼容原则

- `YJZ_TrueJadeSteel` 属于原版 `Metallic` Stuff 分类，因此所有允许金属材质的原版武器、衣物、家具、生产设施、防御设施、艺术品与杂项建筑都会继承真玉钢的颜色、市场价值、生命值、护甲与门开关速度等 Stuff 属性。
- 普通 `Graphic_Single`、`Graphic_Multi` 与 `Graphic_Random` 物件使用原版材质染色即可，不逐件覆写贴图，避免破坏原版样式、DLC 样式与其他 Mod 的 StyleDef。
- 只有原版明确支持 StuffAppearance、带活动门扇，或要求连续拐角纹理的结构，才使用真玉钢专属贴图。

## 已提供专属外观

| 原版 Def | 适配方式 |
|---|---|
| `Wall` | `Graphic_Appearances` + `Graphic_LinkedCornerFiller`，支持直墙、内外角、端头及斜角链接 |
| `Fence` | `Graphic_Appearances` + `Graphic_LinkedAsymmetric`，保留门框连接逻辑 |
| `Column` | 条件材质外观补丁 |
| `Door` | 真玉钢专属活动门扇与菜单图标 |
| `Autodoor` | 真玉钢专属活动门扇与菜单图标 |
| `FenceGate` | 四方向 `Graphic_Multi` 活动门扇与菜单图标 |
| `OrnateDoor` | 双格华丽门活动门扇与菜单图标；原版支架/顶框继续按 Stuff 着色 |
| `NatureShrine_Small` | Royalty 条件加载的专属外观与菜单图标 |
| `NatureShrine_Large` | Royalty 条件加载的专属外观与菜单图标 |
| `GravshipHull` | Odyssey 条件加载的 StuffAppearance 图集；由原版 CornerFiller 自动处理直边、内外角和斜面 |
| `YJZ_TrueJadeTile` | 独立真玉钢地板 TerrainDef |

## 已核查但无需材质适配

- Odyssey `AncientBlastDoor`、`VacBarrier` 与 Anomaly `SecurityDoor` 都显式清空 `stuffCategories`，由固定资源建造或不可建造；它们不是可选择真玉钢的 Stuff 建筑。
- `AnimalFlap` 只允许 `Fabric`、`Leathery`，不接受金属。
- 自然岩壁、虚空建筑等 `CornerFiller` 结构不是 Stuff 建筑，不应接入真玉钢外观。

## 对应原版实现

- `GraphicData.Init`：先创建基础 Graphic，再按 `linkType` 包装为链接 Graphic。
- `Graphic_Appearances.Init`：依据 `StuffAppearanceDef.pathPrefix` 与材质外观 defName 选择专属贴图。
- `Building_Door.DrawAt` / `Building_MultiTileDoor.DrawAt`：由原版负责门扇位移，本 Mod 只按 Stuff 切换门扇材质。
- `Graphic_Multi`：分别读取 `_north`、`_east`、`_south`、`_west`，用于栅栏门方向兼容。
