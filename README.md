# 米莉拉私人拓展—云间子

RimWorld 1.6 私人角色 Mod。

## 设计目标

- 创建唯一的特殊米莉拉角色“云间子”。
- 固定姓名、性别、年龄、背景、外貌、特性和技能。
- 通过 Ariandel Library 登记并维护角色唯一性。
- 防止危险手术、次核扫描、异常复制等机制破坏角色设定。
- 为死亡、失踪、派系变化和读档提供安全恢复机制。

## 目录

- `About`：Mod 元数据与预览图。
- `1.6/Assemblies`：编译后的 C# 程序集。
- `1.6/Defs`：角色、能力、状态、事件等 XML 定义。
- `1.6/Languages`：简体中文及其他语言文本。
- `1.6/Patches`：对 Milira Race 等依赖的 XML 补丁。
- `1.6/Mods`：按已启用 Mod 条件加载的兼容内容。
- `Content/Textures`：跨版本共用贴图。
- `Source`：C# 工程源码。

## 本体建筑

本体已包含建木镇宝匣、合玉炉、青灵聚元池、云阙问道仪、云间养剑台和云间之影。真玉钢材料、熔合配方、合玉炉制作任务、神机与高阶法器配方入口，以及修炼设施连接补丁一并提供，无需启用建筑扩展。

蒲团、白玉台、云间画符台与云间玉筝也由本体提供。其余卧室家具、装饰、门、地砖及奥德赛飞船组件保留在可选的建筑扩展中。

从旧版升级且继续使用建筑扩展时，需同时更新建筑扩展，移除已迁入本体的重复定义和旧程序集中的对应类型。此次迁移保留原有 Def 标识及 C# 类型全名。
