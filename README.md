# 米莉拉私人拓展—云间子

RimWorld 1.6 私人角色 Mod。

## 设计目标

- 创建唯一的特殊米莉拉角色“云间子”。
- 固定姓名、性别、年龄、背景、外貌、特性和技能。
- 通过 Ariandel Library 登记并维护角色唯一性。
- 防止危险手术、次核扫描、异常复制等机制破坏角色设定。
- 为死亡、失踪、派系变化和读档提供安全恢复机制。

## 目录

- `About`：Mod 元数据与预览图。
- `1.6/Assemblies`：编译后的 C# 程序集。
- `1.6/Defs`：角色、能力、状态、事件等 XML 定义。
- `1.6/Languages`：简体中文及其他语言文本。
- `1.6/Patches`：对 Milira Race 等依赖的 XML 补丁。
- `1.6/Mods`：按已启用 Mod 条件加载的兼容内容。
- `Content/Textures`：跨版本共用贴图。
- `Source`：C# 工程源码。

当前仅建立工程骨架，尚未加入角色 Def、贴图或程序集。
