# 米莉拉私人拓展—云间子

RimWorld 1.6 / 1.7 私人角色 Mod。当前开发与实机验证以 RimWorld 1.7.5014 为准；1.6 保留独立运行文件，新的轨道陵墓流程用于 1.7。

## 设计目标

- 创建唯一的特殊米莉拉角色“云间子”。
- 固定姓名、性别、年龄、背景、外貌、特性和技能。
- 通过 Ariandel Library 登记并维护角色唯一性。
- 防止危险手术、次核扫描、异常复制等机制破坏角色设定。
- 为死亡、失踪、派系变化和读档提供安全恢复机制。

## 目录

- `About`：Mod 元数据与预览图。
- `1.6/Assemblies`：编译后的 C# 程序集。
- `1.6/Defs`：角色、能力、状态、事件等 XML 定义。
- `1.6/Languages`：简体中文及其他语言文本。
- `1.6/Patches`：对 Milira Race 等依赖的 XML 补丁。
- `1.6/Mods`：按已启用 Mod 条件加载的兼容内容。
- `Content/Textures`：跨版本共用贴图。
- `Source`：C# 工程源码。

## 本体建筑

本体已包含建木镇宝匣、合玉炉、青灵聚元池、云阙问道仪、云间养剑台和云间之影。真玉钢材料、熔合配方、合玉炉制作任务、神机与高阶法器配方入口，以及修炼设施连接补丁一并提供，无需启用建筑扩展。

蒲团、白玉台、云间画符台与云间玉筝也由本体提供。建筑扩展已停止使用，新陵墓采用原版大理石建筑与陈设，不依赖建筑扩展。

从旧版升级且继续使用建筑扩展时，需同时更新建筑扩展，移除已迁入本体的重复定义和旧程序集中的对应类型。此次迁移保留原有 Def 标识及 C# 类型全名。


## 当前传承开局

西娅·阿纳斯塔西亚乘米莉拉飞船抵达孤云遗冢，初始为白发白翼、羽仿布旅行服。选中西娅并右键研读香案宝卷后，获得中间名“云间子”、传承故事与特性、青色外观，并从练气 10/100 开始修炼。宝卷首次研读后消耗。

陵墓有四间偏殿和独立内殿，六座方舟在传承前封印，其中一座给予青羽机侍。青云纳物匣首次开启仅奖励道袍 1 件和翡翠 75 枚，可容纳 30 组物品、卸下带走。偏殿八座原版物品架存放钢铁 540、塑钢 240、零部件 25、翡翠 200、真玉钢 200、高级零部件 2、逆重板 100。米莉拉材料、食物、药品和燃料仍在船上；不再赠送备用充电站、通用工作台、睡袋或兜帽。

追踪与魔神节点任务共五处：金丹两处、化神三处。节点使用初级 5×5、高级 7×7 素材与受损、虚化状态。更多设计及验证记录见 `Design`。陵墓布局和物资调整用于新开局，不自动重排旧存档。

## 安装与编译

仓库已包含运行所需的程序集与素材，下载后将仓库文件夹放入 RimWorld 的 `Mods` 目录，按 `About/About.xml` 安装前置。孤云遗冢太空开局还需要 Odyssey；不附带第三方模组或游戏程序集。

源码构建需要 .NET 10 SDK、对应游戏程序集和已安装的 Harmony、Ancot Library。默认路径为 Windows Steam 安装目录，可用 MSBuild 参数覆盖 `RimWorldDir`、`WorkshopDir`、`HarmonyAssemblyPath`、`AncotAssemblyPath`。

```powershell
dotnet build Source/YunjianziCultivation.csproj -p:RimWorldVersion=1.7 -p:YunjianziAudit=false
```

`Tools` 包含构建设置、旧 Unity 类型转发引用工程及可选实机检查源码。正式程序集默认不含测试入口。最近的隔离实机检查通过了研读、方舟开启、宝匣奖励、偏殿物资数量、存读档、起飞与降落。
